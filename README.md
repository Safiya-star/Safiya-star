## 🚀 Featured Project

### Event Lead CRM

A production-deployed event lead capture and qualification system built with Python, Flask, SQLite, HTML, and JavaScript.

The application transforms QR-code event interactions into structured CRM data through mobile lead intake, conditional qualification logic, contact matching, consent tracking, and a protected administrative dashboard.

**Highlights**
- Designed a six-table relational database architecture
- Built QR-based mobile lead capture
- Developed conditional business and qualification logic
- Implemented contact matching and duplicate prevention
- Added email consent history and event-specific tracking
- Built a password-protected administrative dashboard
- Deployed the application to a production environment
- Implemented Git/GitHub version control and professional project documentation
